# 🍕 Hackapizza Hackathon

This repo contains the code of the solution presented at the Datapizza Hackathon, `Hackapizza`, by the team 4-omini, composed by me, [Cristian](https://github.com/cris96spa), [Andrea](https://github.com/andreacerasani) and [Alessandro](https://github.com/alecontuIT).

If you're curious about the challenge, you can find more information [here](https://www.kaggle.com/competitions/hackapizza-2025-community) (while this isn't our exact competition, it's the same challenge that was later opened to the public)

For the full story behind our solution and emotions, I've documented our journey in this [blog post](https://giovannigiacometti.github.io/posts/hackathon/)
